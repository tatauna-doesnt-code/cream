# Security reporting

Do not post credentials, private spreadsheets or security exploit details in a
public issue. Use GitHub's **Security → Report a vulnerability** for private reports
when that feature is enabled. If the button is unavailable, open an issue saying
only that you need a private reporting channel; wait for the maintainer to arrange
one before sending details. No security contact address has been invented here.

Include the CREAM/Painter/Windows versions, affected feature and reproduction
steps. Redact personal paths and player information. Never send your GitHub token.

Only the latest beta is currently maintained. There is no guaranteed response
time or security support for earlier releases. Download installers from this
repository's Releases page and check any unexpected update prompt.
